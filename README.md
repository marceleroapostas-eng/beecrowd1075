# Beecrowd 1075 - Resto 2

Este programa resolve o problema 1075 do Beecrowd.

## Descrição

O programa lê um número inteiro N e verifica todos os números entre 1 e 10000 que, quando divididos por N, possuem resto igual a 2.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

A entrada contém um número inteiro N.

## Saída

O programa imprime todos os números entre 1 e 10000 que, quando divididos por N, apresentam resto igual a 2. Cada número deve ser impresso em uma linha.
